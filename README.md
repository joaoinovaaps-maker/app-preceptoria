# App Android – Plataforma da Preceptoria

Aplicativo Android do Programa de Residência Multiprofissional em Saúde da Família (UBS Ildefonso Pedroso, Dourados-MS).
O app abre a plataforma web (https://joaoinovaaps-maker.github.io/Preceptoria/) e acrescenta GPS, câmera/galeria para anexos,
salvamento de PDFs e planilhas, impressão e abertura de links externos.

## Baixar o APK
Vá em **Releases** e baixe o arquivo `Preceptoria-v1.0.X.apk` no celular. Ao instalar, autorize "instalar apps desconhecidos".

## Gerar nova versão
Aba **Actions > Gerar APK da Plataforma > Run workflow** (opcionalmente com outro endereço da plataforma).
Alterações na plataforma web aparecem no app sem gerar novo APK.

## Observações
- Mantenha este repositório **privado**: ele contém a chave de assinatura (`app/preceptoria.jks`).
- Gere sempre por este repositório para que as atualizações instalem por cima da versão anterior.
